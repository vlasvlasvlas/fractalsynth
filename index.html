THE CHAOS GAME: Este generador está basado en el Juego del Caos. El algoritmo toma 3 puntos fijos (anclas armónicas). Partiendo de un punto inicial aleatorio, elige un ancla al azar, dibuja un nuevo punto exactamente en el medio, y repite el proceso infinitamente usando el nuevo punto como origen. Esto genera el fractal conocido como Triángulo de Sierpinski.

SPEED: Controla la velocidad. Valores de 1-50 muestran el algoritmo paso a paso (modo educativo). Valores mayores a 50 inyectan hasta 50 puntos por fotograma para construir el fractal masivo.

ZOOM: Usa la rueda del ratón o los botones [+]/[-]. El nivel de Zoom controla la frecuencia de corte del audio (más cerca = más agudo).

BOX ZOOM: Mantén presionada la tecla SHIFT y arrastra sobre el lienzo para acercarte a un sector específico.

AJUSTES: Presiona el botón [ ⚙ ] para ocultar/mostrar la barra lateral.
